# Hira AI — AI Study & Career Assistant

Hira AI is a friendly AI-powered assistant designed to help students with coding, college assignments, study planning, and career guidance.

## Features
- AI-powered chat using OpenRouter
- Python Flask backend
- SQLite chat history
- Responsive web frontend

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- AI: OpenRouter API
- Database: SQLite

## Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Set the `OPENROUTER_API_KEY` environment variable.
3. Run: `python app.py`

Never publish API keys or other secrets.
